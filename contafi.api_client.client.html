class contafi.api_client.client.bhe.Bhe

Bases: ApiBase

Módulo que permite gestionar BHEs recibidas.

Parámetros:

  • api_token (str) – Token de autenticación del usuario. Si no se proporciona, se intentará obtener de una variable de entorno.

  • api_url (str) – URL base de la API. Si no se proporciona, se usará una URL por defecto.

  • api_version (str) – Versión de la API. Si no se proporciona, se usará una versión por defecto.

  • api_raise_for_status (bool) – Si se debe lanzar una excepción automáticamente para respuestas de error HTTP. Por defecto es True.
